# SC1777Y Driver Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a Zephyr SC1777Y misc driver, SPI emulator, native_sim ztests, and a native_sim sample that exercises all documented semantic flows through public APIs.

**Architecture:** `sc1777y.c` implements the public semantic API and contains private static SPI protocol helpers. `sc1777y_emul.c` registers a SPI emulator that records byte-level command frames and returns deterministic protocol responses. Tests mount the emulator, call public APIs, and assert the emulator's recorded bytes.

**Tech Stack:** Zephyr misc driver, SPI device API, SPI emulator API, devicetree bindings, Kconfig, ztest, native_sim, twister.

## Global Constraints

- Documentation source is `docs/superpowers/specs/2026-07-08-sc1777y-driver-design.md`.
- The sample and tests must call `include/zephyr/drivers/misc/sc1777y.h` public semantic APIs for documented chapter 5 flows.
- The sample must not construct SC1777Y command frames, set CLA/INS/P1/P2 directly, calculate LRC, poll `0x55`, or retry SPI transfers itself.
- `sc1777y.c` contains public API implementations and private `static` transport helpers in the same file.
- Do not create `sc1777y_transport.c` or `sc1777y_transport.h`.
- The emulator validates SC1777Y SPI bytes and returns deterministic data; it does not implement real SM1, SM2, SM3, SM4, or SM7.
- Tests must mount a SC1777Y emulator under native_sim `spi0`, call public APIs, and assert byte-level command data recorded by the emulator.
- Payload limits: general command data up to 2048 bytes, sensor business data must be an 8-byte multiple, session payload crypto must be a 16-byte multiple from 16 to 2048 bytes.

```c
#define DT_DRV_COMPAT senscomm_sc1777y

#include <zephyr/device.h>
#include <zephyr/drivers/spi.h>
#include <zephyr/drivers/misc/sc1777y.h>

struct sc1777y_config {
	struct spi_dt_spec bus;
};

static int sc1777y_init(const struct device *dev)
{
	const struct sc1777y_config *cfg = dev->config;

	return spi_is_ready_dt(&cfg->bus) ? 0 : -ENODEV;
}

#define SC1777Y_DEFINE(inst) \
	static const struct sc1777y_config sc1777y_config_##inst = { \
		.bus = SPI_DT_SPEC_INST_GET(inst, SPI_WORD_SET(8) | SPI_TRANSFER_MSB | \
					    SPI_MODE_CPOL | SPI_MODE_CPHA, 0), \
	}; \
	DEVICE_DT_INST_DEFINE(inst, sc1777y_init, NULL, NULL, &sc1777y_config_##inst, \
			      POST_KERNEL, CONFIG_KERNEL_INIT_PRIORITY_DEVICE, NULL);

DT_INST_FOREACH_STATUS_OKAY(SC1777Y_DEFINE)
```
